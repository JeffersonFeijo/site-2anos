Aniversário - 2 anos
Projeto React + Vite minimal para celebrar 2 anos de namoro.

Como usar:
1. Instale dependências:
   npm install
2. Rode em modo desenvolvimento:
   npm run dev
3. Edite src/App.jsx para:
   - adicionar YOUTUBE_EMBED_ID (const no topo) com o ID do vídeo
   - substituir placeholders da galeria por imagens em /public/images
4. Faça build:
   npm run build

Feito para personalizar — divirta-se! 💕
